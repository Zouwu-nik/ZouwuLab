# Zouwu Lab

**Локальная студия для генерации картинок, видео со звуком, 3D, музыки и голоса.**
Qwen‑Image 2.1, Krea 2, FLUX.3 Klein, MiniMax H3, LTX‑2.5, Hunyuan3D, ACE‑Step, Higgs TTS 3 и OmniVoice в одном окне браузера — на вашей видеокарте, без облака, подписок и нод ComfyUI.

*A local, one-window studio for images, video with sound, 3D, music and voice (Qwen‑Image 2.1, Krea 2, FLUX.3 Klein, MiniMax H3, LTX‑2.5, Hunyuan3D, ACE‑Step, Higgs TTS 3, OmniVoice). Windows + NVIDIA RTX. Interface in Russian.*

## Возможности

**🖼 Картинки** — Qwen‑Image 2.1, Krea 2, FLUX.3 Klein
- генерация по тексту, правка по инструкции, до 4 референсов, img2img;
- турбо‑режимы: 8 шагов вместо 30–40;
- официальные LoRA (турбо, стили Krea 2) и поиск LoRA на Civitai прямо в программе, проверка совместимости;
- редактор с маской, замена лица, персонажи (одно лицо в разных генерациях) — на Qwen‑Image 2.1.

**🎬 Видео со звуком** — MiniMax H3 и LTX‑2.5
- текст → видео, первый кадр, первый + последний кадр;
- MiniMax H3: до 9 референсов (люди, места, предметы) с отметками `@img1` в промпте;
- LTX‑2.5: апскейл ×2 с «упором на исходник» — лицо со стартовой картинки не размывается.

**🧊 3D** — Hunyuan3D
- модель по одной картинке или по нескольким ракурсам (спереди, слева, сзади, справа);
- автоудаление фона; результат — сетка без текстуры: просмотр прямо в программе, экспорт GLB для Blender, Unreal, Unity.

**🎵 Музыка** — ACE‑Step 1.5, MiniMax Music 3, YuE2, Stable Audio 3
- песни с вокалом (в том числе на русском), инструментал, фоны и звуки.

**🗣 Речь** — Higgs TTS 3
- текст → живая речь: 100+ языков, 21 эмоция, шёпот, крик, смех, вздохи, паузы;
- голос — случайный или клон по 5–15 с записи; диалоги разными голосами;
- **✨ авторазметка**: помощник сам расставляет эмоции, паузы и звуки в тексте.

**🎙 Голос** — переозвучка роликов голосом по образцу (OmniVoice)
- отделение голоса от музыки и шумов, распознавание речи (Whisper), правка фраз;
- новая речь укладывается в тайминг оригинала, эмоции, паузы и громкость каждой фразы; озвучка просто текста.

**✨ Помощник** — локальная LLM (llama.cpp) пишет и улучшает промпты по правилам каждой нейросети, видит картинки (если у модели есть зрение), сочиняет стиль и текст песен, расставляет теги эмоций для «Речи».

**📊 Мастерская** — оценки результатов, статистика, свод правил и автооценка картинок.

## Установка

1. Скачайте архив из [Releases](../../releases) (или кнопка **Code → Download ZIP**) и распакуйте на любой диск, лучше в короткий путь без пробелов и русских букв, например `C:\ZouwuLab`. Не в Program Files и не в OneDrive.
2. Запустите `install.bat` — он скачает Python, PyTorch с CUDA и движок внутрь этой папки (в систему ничего не ставится).
3. Запустите `start.bat` — откроется браузер с программой.
4. **Модели → Скачать рекомендованные** — выберите нейросеть и скачайте файлы со звёздочкой.

**Если у вас была ранняя сборка:** распакуйте эту версию поверх старой папки (модели и настройки сохранятся) и один раз запустите `update_engine.bat` — для FLUX.3, 3D и музыки нужен движок новой версии.

Подробная инструкция — в [README.txt](README.txt).

## Как это работает

- **Всё внутри одной папки.** `install.bat` скачивает в неё Python 3.12, PyTorch с CUDA и движок ComfyUI 0.42.3. В систему ничего не ставится: удалили папку — удалили программу. Папку можно переносить на другой диск или компьютер.
- **Программа — локальный сервер** (`start.bat`), интерфейс открывается в браузере по адресу `http://127.0.0.1:7860`. В интернет ничего не уходит, кроме скачивания моделей и поиска LoRA на Civitai.
- **Движок без нодов.** ComfyUI работает в фоне без своего интерфейса: программа сама собирает граф под выбранную нейросеть и режим (текст, правка, кадры, референсы) по официальным шаблонам.
- **Каждая нейросеть — со своими настройками.** Модели, промпт и стек LoRA у каждой свои; программа подставляет только подходящие файлы и предупреждает, если выбран файл чужой нейросети.
- **Видеопамять — одной задаче.** При переключении нейросети или вкладки предыдущая модель выгружается сама. Голос, речь и помощник работают отдельными процессами и тоже освобождают видеокарту, когда не нужны.
- **Память под ваш компьютер.** Профиль «Авто» подстраивает работу с ОЗУ под её объём (32 или 64 ГБ), предохранитель останавливает генерацию, если ОЗУ кончается.
- **Модели качаются только по кнопке** — из каталога «Модели → Скачать рекомендованные», с подсказкой, какой файл под какое железо (NVFP4 для RTX 50xx, int8/int4 для RTX 30/40, GGUF при малой видеопамяти).
- **Результаты** — в папке `output` (картинки, видео, музыка, речь, 3D) и в галерее программы, вместе с настройками генерации.
