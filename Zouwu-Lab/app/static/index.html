Настройки

Создать: huggingface.co → Settings → Access Tokens (тип Read). Затем на странице модели нажмите «Agree and access repository».

Создать: civitai.red → аккаунт → Settings → API Keys → Add API key. Аккаунт общий для civitai.red и civitai.com.

Память

То, что не влезает в видеопамять, движок и так выгружает в ОЗУ. Профили не дают ему занять всю оперативную память: не закрепляют память намертво (pinned), держат запас свободной, «Минимум» ещё и не кэширует модели и читает веса прямо с диска (лучше всего с SSD). При смене профиля движок перезапустится.

При изменении параметров движок перезапустится.

Разговоры и оценки сохраняются в журнал — пригодятся для итогового системного промпта.

      

    

    

      

        
        
      

      

      

    

    

      

        
        
        
        
      

      
Журнал хранится в папке journal программы и копится неделями: отчёты его не очищают, обновления программы не трогают, раз в день делается резервная копия (journal\backup).

      

      

      

        
Автооценка — вторая «пара глаз» рядом с вашими звёздами

        
Нейросети, обученные на выборе тысяч людей, ставят каждой новой картинке балл. Они не знают ваш вкус — поэтому здесь видно, насколько они с вами совпадают. Если совпадают хорошо, в будущем помощник сможет сам отсеивать слабые варианты. Обучены в основном на обычном (не 18+) контенте — на откровенных картинках могут ошибаться.

        

        

          
          
          
        

        

        

      

      

        
Журналы с разных компьютеров

        

        

        

          
          
          
        

        

        

        
Каждый компьютер кладёт в общую папку только свой файл и забирает файлы остальных — раз в 10 минут, через минуту после новой оценки и при запуске. Повторы не дублируются, правила с одинаковым текстом объединяются.

      

      
🗑 Сбросить статистику…
        
Оценки и разговоры выбранной нейросети (или всех — по переключателю вверху) удаляются из статистики. Перед этим вся база копируется в journal\archive — при необходимости её можно вернуть.
